Política de privacidad

Información clara sobre los datos que puede tratar esta web y las decisiones de privacidad aplicadas al proyecto.

Principio general

La navegación ordinaria por esta web no exige crear una cuenta ni facilitar datos personales obligatorios.

Peregrino no utiliza la actividad espiritual para elaborar perfiles personales o puntuaciones de fe.

Datos guardados en el navegador

Algunas funciones pueden utilizar almacenamiento local del navegador. En la maqueta actual se guarda, por ejemplo, el alias del muro del Rincón de la Luz y la preferencia ficticia de vista Visitante o Miembro.

Estos datos permanecen en el dispositivo hasta que se borran desde la web o desde la configuración del navegador.

Nombres incluidos en enlaces

Las páginas de invitación o regalo pueden recibir un nombre mediante parámetros como nombre, para o n. El navegador utiliza ese valor para personalizar el texto.

La versión actual no envía ese nombre a un servidor de Peregrino.

Fuentes de datos y herramientas

La Biblioteca y El mundo está de Cursillo pueden consultar fuentes publicadas para mostrar oraciones, Cursillos y palancas. La información técnica necesaria para esas consultas se limita a la comunicación normal entre el navegador y dichos servicios.

Servicios de terceros

Google Play, App Store, PayPal, WhatsApp y otros servicios enlazados aplican sus propias políticas de privacidad.

Consultas y derechos

Puedes plantear consultas relacionadas con privacidad escribiendo a peregrinoapp@outlook.es.
